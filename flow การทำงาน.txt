Flow 1: Data Input (การนำข้อมูลเข้าระบบตั้งต้น)
Flow นี้คือการสร้าง "ทรัพยากร" ทั้งหมดของโรงเรียนเพื่อเก็บไว้เป็นฐานข้อมูลส่วนกลาง (Master Data)

ตั้งค่าระบบพื้นฐาน: ผู้ดูแลระบบเข้าสู่ UI ตั้งค่า เพื่อกำหนดปีการศึกษา ภาคเรียน และโครงสร้างเวลา (เช่น วันละ 8 คาบ เริ่มกี่โมง)

นำเข้าข้อมูลบุคลากรและสถานที่: นำเข้าข้อมูลรายชื่อครู รายชื่อชั้นเรียนทั้งหมด และสถานที่/ห้องเรียน เข้าสู่ระบบ (ผ่านการคีย์ในฟอร์ม UI หรือการอัปโหลดไฟล์ Excel/CSV)

นำเข้าข้อมูลวิชาเรียน: เพิ่มรหัสวิชาและชื่อวิชาทั้งหมดของเทอมนั้น

บันทึกข้อมูล: ระบบจัดเก็บข้อมูลทั้งหมดลงในฐานข้อมูล เพื่อเตรียมส่งต่อให้ Flow ถัดไปดึงไปใช้งานเป็นตัวเลือก

Flow 2: Relationship Mapping (การสร้างความสัมพันธ์และเงื่อนไข)
Flow นี้คือการนำข้อมูลจาก Flow 1 มาผูกเข้าด้วยกัน เพื่อสร้างเป็น "ภาระงาน" และ "ข้อจำกัด" ให้กับอัลกอริทึม

ล็อกเวลาส่วนกลาง (Fixed Events): ผู้จัดตารางเข้า UI กิจกรรมส่วนรวม เลือกคาบเวลาที่แน่นอนเพื่อล็อกไว้สำหรับกิจกรรมลูกเสือ ชุมนุม หรือการประชุมฝ่าย โดยเลือกกลุ่มครูและนักเรียนที่เกี่ยวข้อง

ล็อกเวลาส่วนตัว (Unavailability): ผู้จัดตารางหรือครูแต่ละท่าน เข้า UI จัดการเวลา เพื่อบล็อกคาบที่ไม่สามารถสอนได้ (ติดงานพิเศษ)

กำหนดคาบพักเที่ยง: ระบุเงื่อนไขเวลาพักสำหรับนักเรียนแต่ละระดับชั้น เพื่อกันคาบว่างไว้ล่วงหน้า

สร้างภาระงานสอน (Assignments): ผู้ใช้งานเปิด UI ฟอร์มภาระงานสอน

ผูกความสัมพันธ์ผ่าน UI: ผู้ใช้งานดึงข้อมูลด้วยการกดเลือกจาก Dropdown/Chips ประกอบด้วย วิชา + รายชื่อครู (เลือกได้มากกว่า 1) + ชั้นเรียน (เลือกได้มากกว่า 1) + สถานที่ + รูปแบบคาบเดี่ยว/คู่

บันทึกเงื่อนไข: ระบบแปลงข้อมูลความสัมพันธ์ทั้งหมดนี้เป็น Array หรือ List ส่งไปเก็บในฐานข้อมูล เพื่อเตรียมประมวลผล

Flow 3: Processing (การประมวลผลจัดตารางอัตโนมัติ)
Flow นี้คือการทำงานของระบบหลังบ้าน (Backend Engine) ซึ่งเป็นหัวใจหลักในการไขปริศนาตารางสอน

ตรวจสอบความพร้อม (Pre-check): ระบบรวบรวมข้อมูลภาระงานและข้อจำกัดทั้งหมด มาแสดงบน UI แดชบอร์ด เพื่อให้ผู้ใช้งานตรวจสอบความถูกต้องก่อนกดปุ่ม "ประมวลผล"

ส่งชุดข้อมูลเข้า Solver: เมื่อกดรัน ระบบหลังบ้านจะส่งชุดข้อมูลความสัมพันธ์ทั้งหมด (Master Data + Constraints + Assignments) เข้าสู่อัลกอริทึมคำนวณ (เช่น Python OR-Tools)

คำนวณสมการ: อัลกอริทึมจะทำการจับคู่ (Match) คาบว่าง ครู ห้องเรียน และนักเรียน โดยรับประกันว่ากฎทุกข้อต้องเป็นจริง เช่น ครูสอนร่วมต้องว่างตรงกัน นักเรียนควบห้องต้องว่างตรงกัน และไม่มีใครสอนเกินลิมิต

คืนค่าผลลัพธ์: เมื่ออัลกอริทึมพบคำตอบที่สมบูรณ์แบบ จะคืนค่าข้อมูลตารางสอนทั้งหมดกลับมายังระบบฐานข้อมูล

แสดงผล: ระบบนำข้อมูลมาวาดลงบน UI ตารางสอนแบบออนไลน์ ให้ครูและนักเรียนสามารถล็อคอินเข้ามาดูตารางของตัวเองได้ทันที รวมถึงสามารถปรับแก้แบบแมนนวลในขั้นสุดท้ายได้หากจำเป็น
flow ที่ 4 แนะนำ การจัดตาราง
ควรเริ่มจัด วิชาที่ใช้ ห้องเรียน คอมพิวเตอร์ก่อน 
หลังจากนั้น ค่อยจัด คาบที่ครู สอน ลูกเสือ และ สอนชุมนุม    สอน ประชุมระดับกับนักเรียนประจำชั้น
จัดคาบคู่ ประเภท ชั้นเรียน 1 ชั้น เรียน 2 วิชา ในคาบเดียวกัน ครูเข้าสอน 2 คน 
หลังจากนั้น จัดตารางสอน วิชาที่เป็น คาบคู่ก่อน 
หลังจากนั้น ลงวิชา ที่ สอนนักเรียน ชั้นเรียนเดียวกัน แต่ครูเข้าสอน มากกว่า 1 คน คือ 2-3 คน 
ที่เหลือคือ ค่อยลง ครู 1 คน ต่อ 1 ชั้นเรียน 
เช็คเงื่อนไขการจัดตารางด้วยว่า 1 รหัสวิชา ใน 1 วัน ห้ามเรียนเกิน 1 คาบ
